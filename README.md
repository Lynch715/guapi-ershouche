开一家二手车行，从 500 万做到 1 个亿——老老实实赚，还是挖坑赚快钱，你自己选。

纯 HTML 与经典脚本，无框架、无构建、无 npm 运行依赖。下载完整项目后双击 `index.html`，或打开在线试玩。建议使用 iOS 14 / Safari 14 及以上、现代 Chrome / Edge / Firefox。

## v1.1.1 审计修复

事件客户会按车况、质保和金融方案估价，挂牌高价不再让砍价、置换、批量采购或额外服务费突破预算；收藏家保留明确的收藏溢价。事件报价在确认前展示，实际成交统一进入本月清单，零售与批发、拍卖、甩卖分别显示。

同笔销售只可退车退款一次，剩余投诉、隐患、质保与关联民间担保一并结清。退回车辆完整检测后再入库。可识别的旧版重复退车档会合并车辆和已知车况，保留原账面资金；信息不足的异常档仍拒绝读取，原文件保持。

导入成交记录仅保留数据字段，车辆美术由页面重新生成；文件中的 HTML 不会被执行。月底黑化达到100会先触发查封。同行事件降价后停止自动定价，可在库存恢复；二次抵押摆平费用不重复计入车辆成本。

新招聘员工（含上门人才）的工资、行动点和所有加成统一从下月开始。旧档已有员工继续在职。月结保存失败有明确提示，菜单显示“尚未保存”，可重试或导出备份。弹窗隔离背景、限制键盘焦点并在关闭后恢复；浏览器缩放重新开放，小字增大。

四级门店改为更高的双展厅与宽前院，保留原版备份；头像和车辆展示以暖金色细节统一。良心结局文案不再虚构清白历史，脏污说明与外观表现同步。自动进度及三档存档键、存档版本1保持兼容。

## 怎么玩

1. 选本钱和地段，开张。
2. 花行动点去看车、验车，挑值得收的车入库。
3. 整备、挂牌、选质保与金融方案，月底等客户。
4. 管住现金、口碑和黑化；做到目标净资产就通关，资金链断裂、查封或门店法拍会结束本局。

收车有散户、置换车、拍卖、同行和拖车场。车辆显性毛病直接看得见，隐性问题得靠检测；你知道的车况和买家看到的可能不一样。掩盖问题能赚快钱，但售后、催收和抽查的旧账会慢慢找上门。

## 拒绝车源与买卖议价

收车卡片可直接「拒绝这台车」，不花钱、不花行动点，只从本批移除；拒绝或买下后保留列表浏览位置。卖家支持最多三轮「试探砍价 / 认真压价 / 狠砍一刀」，会接受或还价，也可能失去耐心离场。谈后的报价、性格、耐心与轮次随进度保存，现场验车仍按揭示的车况重估，拖车费另算。拍卖平台保持按报价成交，也可拒绝车源。

部分卖家已经报实价，会守价；置换车和同行车源更常见这种情况。卖家不再每台车轻砍一下就必降3%。不同性格的对话随轮次变化，可展开查看本次报价记录，金额显示保留实际百元差价。

库存可一键降价 3%，之后停止自动跟价，随时可恢复自动定价。也可花 1 点「接待买家」，每台车每月主动接待一位，选择多让一点、各退一步或坚持原价，最多三轮；抬价可能谈崩。谈好后点击成交才收款出库，按实际成交价记入当月明细，并沿用质保、金融与售后规则。暂离或刷新可以续谈，不重抽买家；本月送客或谈崩，下月才能再主动接待。未主动接待、未谈成的库存仍正常参加月底自动零售。

买家会根据性格逐轮让步，有预算也未必立刻全部拿出来。修改车况、质保或金融方案会让同一位买家重新核价，保留原来的估价偏好、轮次和耐心；临时抬价不增加老买家的预算，公开降价后也不能继续按更高的旧价卖给他。成交前再核对一次条件。手机上的成交、送客按钮固定在底部，展开报价记录也能直接操作。

旧存档无需转换，存档版本、自动续玩键与三个手动档位键保持原样。议价仍是可选操作，未主动接待的车辆照常参加月底零售；v1.1.1 的正确性修复适用于所有经营路线。

经理与技师增加行动点，销售带客流，财务减轻罚款和赔偿。门店可以升到 5 级、最多 180 个车位；库存每页 20 台，车库最多展示 45 个车位。

## 引导、菜单与声音

首局有 6 步可跳过的开张指南。右上角菜单集中了存档、帮助、重播引导、新开一局、音效和震动，版本号在存档页底部。

按钮、成交、月结、出事、通关的音效由 WebAudio 合成，没有音频文件。静音同时关闭震动；震动另有独立开关，设备不支持时跳过。系统开启“减少动态效果”后，过场、数字滚动和抖动都会停下，经营照常。

## 再次打开与新开一局

首次进入可直接选择资金和地段。已有自动进度或手动档位时，再次打开会进入独立的「继续上次」页，展示上次月份、门店、资产、现金和库存，点击即可续玩，也能选择其他档位或导入。

「新开一局」单独进入资金/地段设置；可返回继续页。浏览设置、取消开张和读取摘要都不改原存档；确认开张才替换自动续玩，三个手动档位保留。只有手动档或自动档损坏时，会引导选择档位/导入备份，不盲目载入。

## 存档与换设备

当前进度自动保留到本浏览器，另有三个独立的手动档位。在菜单中选择档位「保存到此」，可保留不同阶段的快照；当前进度和每个档位都能单独下载 `.json` 存档。文件名包含档位与月份，可直接用于游戏内导入。异常档位仍可下载原始 `.txt` 备份供恢复。继续经营和新开局不会覆盖手动档位，覆盖已有档位前会显示原进度并确认。

导入时选择 `.json` 文件（兼容旧版 `.txt`），再选择档位 1～3。页面只显示所选文件名，不提供文本复制或粘贴入口。校验和确认后只写入所选档位，不立即替换当前游戏；点击该档位「读取」才切换进度。坏文件、写入失败或等待确认时档位被其他标签页改动，都不会覆盖原档。

旧自动存档首次升级会备份到空的档位 1，原自动续玩仍保留；已有档位 1 时不会覆盖。三个档位分别保存在 `usedcar_sim_slot_1_v1`～`usedcar_sim_slot_3_v1`，导出仍是原版存档格式。自动存档键是 `usedcar_sim_save_v1`。本地文件和在线网站的浏览器存储分开：从原来的本地版本搬到在线版时，先导出文件，再导入到在线版。

引导、静音、震动偏好单独保存，不混入存档。旧存档没有开张日期时会显示记不清的老店，不编造时间。

## 主屏幕安全区与地段预览

地段卡直接复用 `G.Art.store(1, 地段)`，显示该地段背景和一级门店。手机为卡片顶部全宽2.4:1，圆点与说明在图下；电脑为160×80左图右文。缩略图单独取景与提亮，露出高楼、烟囱、展厅和彩旗，不修改原素材。

顶部固定遮挡条使用 `--safe-area-top: env(safe-area-inset-top, 0px)`，在普通页面上层、弹窗下层；开始页、HUD、提示条和弹窗统一避开该区域。普通浏览器环境为0时不占额外空间。开发验收可覆盖变量为47px，截图逐像素核对顶部底色；这是模拟检查，不能替代实体iPhone主屏模式验收。

## 图标与美术

瓜皮车图标是原创代码绘制，采用深浅绿车身、瓜皮帽、金色双轮与深色背景；没有使用真实公司的图形或广告语。所有标准 favicon、苹果主屏幕和分享图保留 PNG / ICO。

运行美术统一为 WebP：车辆与俯视图、建筑质量 85，贴图质量 80，背景 / 头像 / 结局 / 主视觉质量 82，alpha 无损；24 张染色遮罩完全无损。缺车图会退回矢量画。原 PNG / JPG 母版保留在本地 `assets_original/`，不提交到仓库；参考与源图同样不发布。

更新美术的本地流程（开发工具需要 Pillow、numpy，不影响游戏运行）：

```bash
# 首次分离母版，之后无需再加 --prepare
python3 tools/build_webp.py --prepare
# 改母版车图后：先重做遮罩，再生成运行图
python3 tools/make_paint_masks.py
python3 tools/build_webp.py
# 重新生成标准图标
python3 tools/build_icons.py
# 本地预览启动后，按当前首图生成 1200×630 分享图
PLAYWRIGHT_MODULE=/已有的/playwright node tools/build_share.js
```

开始页提供三套可切换首图。改 `js/art.js` 顶部的 `G.CONFIG.keyart`：`a` 是西瓜皮车与心虚车商（默认），`b` 是现有车图代码拼装，`c` 是车行灯箱招牌。A开始页统一使用4:5竖图；宽屏焦点同时保留西瓜车和墨镜车商，C仍按手机/桌面分别构图。≥1000px 开始页最大宽1200px、两栏3:2居中，左图高度为右栏内容高度与70vh中较大者，右栏在图内垂直居中，开张按钮距末张地段卡24px。手机菜单浮在首图右上内缩12px，带半透明底和毛玻璃；电脑菜单位于内容区右上。单选控件采用空心圈/金色圆点和150ms过渡。标题、副标题和标语由 HTML/CSS 排版。A旧横图保留供分享图构建，开始页不预载或请求它。切换不改变经营或存档。新图母版仍在本地 `assets_original/ui/`，经 `tools/build_webp.py` 生成运行图。

`G.ASSET_PACK` 可以单独关闭美术组并退回矢量画。路径扩展名统一由 `G.ASSET_EXT` 提供。母版、运行图与图标分开，不做 PNG 兜底。
