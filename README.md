# 瓜皮二手车 · 二手车商模拟器 v1.0

开一家二手车行，从 500 万做到 1 个亿——老老实实赚，还是挖坑赚快钱，你自己选。

[在线试玩](https://lynch715.github.io/guapi-ershouche/) · [GitHub 仓库](https://github.com/Lynch715/guapi-ershouche)

![瓜皮二手车开始界面](docs/preview.webp)

纯 HTML 与经典脚本，无框架、无构建、无 npm 运行依赖。下载完整项目后双击 `index.html`，或打开在线试玩。建议使用 iOS 14 / Safari 14 及以上、现代 Chrome / Edge / Firefox。

## 怎么玩

1. 选本钱和地段，开张。
2. 花行动点去看车、验车，挑值得收的车入库。
3. 整备、挂牌、选质保与金融方案，月底等客户。
4. 管住现金、口碑和黑化；做到目标净资产就通关，资金链断裂、查封或门店法拍会结束本局。

收车有散户、置换车、拍卖、同行和拖车场。车辆显性毛病直接看得见，隐性问题得靠检测；你知道的车况和买家看到的可能不一样。掩盖问题能赚快钱，但售后、催收和抽查的旧账会慢慢找上门。

经理与技师增加行动点，销售带客流，财务减轻罚款和赔偿。门店可以升到 5 级、最多 180 个车位；库存每页 20 台，车库最多展示 45 个车位。

## 引导、菜单与声音

首局有 6 步可跳过的开张指南。右上角菜单集中了存档、帮助、重播引导、新开一局、音效和震动，版本号在存档页底部。

按钮、成交、月结、出事、通关的音效由 WebAudio 合成，没有音频文件。静音同时关闭震动；震动另有独立开关，设备不支持时跳过。系统开启“减少动态效果”后，过场、数字滚动和抖动都会停下，经营照常。

## 存档与换设备

进度自动存到当前浏览器。菜单里可以复制存档码、下载 `.txt`，也能粘贴或选择文件恢复；导入和新开局都要再确认一次，坏存档不会替换原进度。

旧存档仍可继续玩，自动存档键是 `usedcar_sim_save_v1`。本地文件和在线网站的浏览器存储分开：从原来的本地版本搬到在线版时，先导出再导入。浏览器不让复制时，可以长按文本框手动复制。

引导、静音、震动偏好单独保存，不混入存档。旧存档没有开张日期时会显示记不清的老店，不编造时间。

## 图标与美术

瓜皮车图标是原创代码绘制，采用深浅绿车身、瓜皮帽、金色双轮与深色背景；没有使用真实公司的图形或广告语。所有标准 favicon、苹果主屏幕和分享图保留 PNG / ICO。

运行美术统一为 WebP：车辆与俯视图、建筑质量 85，贴图质量 80，背景 / 头像 / 结局 / 主视觉质量 82，alpha 无损；24 张染色遮罩完全无损。缺车图会退回矢量画。原 PNG / JPG 母版保留在本地 `assets_original/`，不提交到仓库；参考与源图同样不发布。

更新美术的本地流程（开发工具需要 Pillow、numpy，不影响游戏运行）：

```bash
# 首次分离母版，之后无需再加 --prepare
python3 tools/build_webp.py --prepare
# 改母版车图后：先重做遮罩，再生成运行图
python3 tools/make_paint_masks.py
python3 tools/build_webp.py
# 重新生成标准图标
python3 tools/build_icons.py
# 本地预览启动后，按当前首图生成 1200×630 分享图
PLAYWRIGHT_MODULE=/已有的/playwright node tools/build_share.js
```

开始页提供三套可切换首图。改 `js/art.js` 顶部的 `G.CONFIG.keyart`：`a` 是西瓜皮车与心虚车商（默认），`b` 是现有车图代码拼装，`c` 是车行灯箱招牌。A/C 的手机与桌面图片分别构图；手机完整显示竖图。≥1000px 开始页最大宽1200px、两栏3:2居中，A桌面横图按西瓜车焦点cover铺满至少75vh并与右栏等高。菜单位于内容区右上，单选控件采用空心圈/金色圆点和150ms过渡。标题、副标题和标语由 HTML/CSS 排版。切换不改变经营或存档。新图母版仍在本地 `assets_original/ui/`，经 `tools/build_webp.py` 生成运行图。

`G.ASSET_PACK` 可以单独关闭美术组并退回矢量画。路径扩展名统一由 `G.ASSET_EXT` 提供。母版、运行图与图标分开，不做 PNG 兜底。

## 文件结构

```text
index.html               页面入口与分享信息
manifest.webmanifest     主屏幕显示与图标
css/style.css            手机 / 桌面布局、动效与安全区
css/keyart.css           三种开始页首图与灯箱标题
js/data.js               数值、车型、渠道、岗位、文案
js/util.js               带种子随机数、金额格式
js/car.js                车辆、估价与评级
js/game.js               经营、销售、月结、事件、存档
js/staff.js              员工与招聘
js/finance.js            经营贷、买家车贷、车主抵押
js/art.js                WebP 美术、染色、矢量后备
js/events.js             35 张事件卡
js/mobile.js             触屏防缩放与点击细节
js/feedback.js           数字反馈与震动
js/save-ui.js            存档菜单、文件导入导出
js/ui.js                 页面和月结界面
js/tutorial.js           首局引导
js/sound.js              合成音效
assets/                  WebP 美术与标准 PNG / ICO 图标
docs/preview.webp        游戏截图
tools/test-events.js     引擎与存档回归
tools/browser-check.js   可选 Playwright 浏览器验收
tools/keyart-check.js    三案五尺寸首图检查与截图
tools/start-screen-check.js  开始页布局、单选与手机对照检查
tools/keyart-compare.py  首图截图联系表
tools/build_share.js     当前首图的 CSS 分享图
tools/text-audit.js      玩家文案提取
tools/build_webp.py      WebP 构建
tools/make_paint_masks.py 母版染色遮罩
tools/build_icons.py     原创图标生成
tools/sim.js             无界面数值模拟
```

引擎七个文件不依赖 DOM，随机数只走 `G.rand` 系列。版本 v1.0 只改表现、文案和工程，经营数值沿用 v0.9。

## 开发检查

```bash
node tools/test-events.js
node tools/sim.js 200 120 small suburb
# 用本机已安装的 Playwright 做浏览器验收
python3 -m http.server 8893 --bind 127.0.0.1
PLAYWRIGHT_MODULE=/已有的/playwright node tools/browser-check.js
```

72 项断言、35 张事件卡的 266 个选项组合覆盖员工、金融、事件、旧存档续玩 24 月、坏存档保护。浏览器检查包含 375 / 390 / 430 / 1280 / 1440 / 1920 六种视口、触屏、存档下载及文件导入、三个月经营、结算防连点和偏好持久化。首图另检查三案 × 五尺寸、40px 标题、资金卡首屏可见、招牌定位、构图适配和美术关闭后备；另验收单选点击/方向键/过渡/减少动态效果，宽屏居中、3:2、首图与右栏等高及含继续按钮的首屏布局。合成触屏事件不能替代所有真实 iOS 手势或真人听音。
